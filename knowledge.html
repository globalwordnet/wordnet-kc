A working route

From scope to reusable resource

01

Define the purpose

Describe the users, language variety, domains, parts of speech, intended coverage and applications before selecting data or tools.

02

Choose the semantic model

Define what counts as a lexical entry, sense and synset, then document the relations and editorial criteria consistently.

03

Build for interoperability

Use stable identifiers, explicit metadata and a shared exchange format so that the resource can be validated and reused.

04

Validate and publish

Check structural validity, relation consistency, licensing, documentation, versioning and citation information before release.
